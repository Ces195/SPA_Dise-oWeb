# SPA_Dise-oWeb
Proyecto web de gestión empresarial sobre un SPA.
Objetivo: Gestionar conflictos efectivamente y no permitir reservar una cabina o un especialista si ya están ocupados.
Criterios:
  *Uso de HTML y JavaScript
  *Uso de base de datos PostgreSQl
  *Uso de PHP 8.2+
  *Servidor en Apache
  *Uso extensivo de GitHub
